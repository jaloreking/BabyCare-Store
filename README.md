# Kids Shirt Studio - Premium Boys Shirts Website

A professional, modern, and premium static e-commerce website for boys shirts, designed specifically for GitHub Pages hosting.

## 📋 Overview

Kids Shirt Studio is a complete static e-commerce website for a premium kids boys shirt brand. It features a modern design, fully functional shopping cart, wishlist, product search, and a beautiful user experience.

**Brand:** Kids Shirt Studio
**Tagline:** Smart Styles for Little Gentlemen
**Target:** Boys aged 2-14 years

## 🚀 Features

- ✅ Fully static - No backend required
- ✅ Responsive design (Mobile, Tablet, Desktop)
- ✅ Product catalog with 12+ sample products
- ✅ Shopping cart with localStorage
- ✅ Wishlist functionality
- ✅ Product search
- ✅ Product filtering and sorting
- ✅ Product detail page with gallery
- ✅ WhatsApp order integration
- ✅ Newsletter subscription
- ✅ SEO optimized
- ✅ JSON-LD structured data
- ✅ Google Fonts (Poppins)
- ✅ Premium modern design
