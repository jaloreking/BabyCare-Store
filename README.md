# LITTLE GENT — Premium Boys Shirts

GitHub Pages-ready static website.

## Files
- `index.html` — main page
- `style.css` — complete responsive design
- `products.js` — product catalogue and image URLs
- `script.js` — filters, search, bag/cart and WhatsApp order flow
- `robots.txt` / `sitemap.xml` / `manifest.json`
- `PHOTO-SOURCES.md` — online photo sources and usage notes

## Publish on GitHub
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the live Pages URL.

## Before launch
- Replace the demo WhatsApp number `919999999999` in `index.html` and `script.js`.
- Replace `hello@example.com`.
- Replace the brand name/logo if needed.
- Replace demo product photos with your own shirt photos when available.
- Update prices, sizes and product names in `products.js`.
- Update `sitemap.xml` with your actual GitHub Pages/custom-domain URL.

The catalogue currently uses externally hosted Pexels image URLs so the ZIP stays lightweight. For the final commercial launch, download/use photos according to the current Pexels license and keep a record of the source pages.
